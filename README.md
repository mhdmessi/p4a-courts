# P4A Courts

Saturday 7am open play at Pickleball4ALL: courts set by rating, fair sit-outs, scores, rankings and a DUPR upload file.

- App: https://mhdmessi.github.io/p4a-courts/ (on iPhone, open in Safari, then Share → Add to Home Screen)
- Group rankings: https://mhdmessi.github.io/p4a-courts/rankings.html

`node test.js` runs the fairness simulations.
