# P4A Courts

Saturday 7am open play at Pickleball4ALL: sign-ups, courts set by rating, fair sit-outs, live scores on every phone, rankings and a DUPR upload file.

- App: https://mhdmessi.github.io/p4a-courts/ (on iPhone, open in Safari, then Share → Add to Home Screen)
- Sign-up link for the group: https://mhdmessi.github.io/p4a-courts/?go=signup
- Rankings: https://mhdmessi.github.io/p4a-courts/rankings.html
- Practice mode (separate test data): https://mhdmessi.github.io/p4a-courts/?practice=1

`node test.js` runs the fairness simulations.
